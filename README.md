# BOOK-VERDICT

A JavaScript-powered interactive advent calendar featuring a hand-designed bookstore apartment facade with unlockable rewards behind clickable windows.

Users can explore an illustrated stone apartment building, click on its windows, and discover unique rewards, surprises, and seasonal content hidden behind each door. At the base of the building sits a charming bookstore that serves as the heart of the experience.

## Features

- Interactive clickable windows
- Reward reveal system
- Cozy illustrated bookstore apartment aesthetic
- Date-based unlocking
- Persistent progress using local storage
- Responsive web design
- Built with HTML, CSS, and JavaScript
